How EmoSense AI works

Three local components connect the webcam, model, and dashboard. Timing depends on your hardware and setup.

01
📷

Webcam Capture

OpenCV attempts to open an available webcam and streams readable frames to the dashboard. A working camera is required.

02
🧠

Emotion Classification

A background thread sends the latest frame to DeepFace approximately every 0.2 seconds. The model returns its supported emotion labels with scores when a face is detected.

03
🔔

Teacher Alert

For selected negative labels, the system can speak an audio alert after a sustained interval. This is an experimental signal for human review, not a diagnosis.

Features

Built for local experimentation

The interface is designed to make a webcam and emotion-model prototype easier to inspect during testing.

⚡

Real-Time Detection

DeepFace runs in a dedicated background thread so model work does not block the camera loop. Update speed depends on the computer.

🔇

Fully Offline

After dependencies and model files are installed, inference runs locally. The first setup may require downloads, and hardware support still matters.

📊

Live Dashboard

Open http://localhost:5000 in any browser. See current emotion, confidence bars, timeline, session history.

🔊

Audio Alerts

pyttsx3 can speak an alert for selected labels. Audio support depends on the operating system and installed voices.

📋

Session History

Every detection logged with timestamp and confidence. Export a full session report as a text file after the class ends.

💰

Zero Cost

Uses open-source components and has no built-in subscription or cloud service. Installation still requires compatible Python packages and hardware.

Get Started

Up and running in 3 steps

Install the compatible dependencies, connect a webcam, and start the Flask server. The first DeepFace model load can take longer than later runs.

1
Install all libraries with pip install -r requirements.txt — only needed once
2
Run the backend with python app.py — camera and emotion detection start automatically
3
Open http://localhost:5000 in Chrome — live dashboard with real webcam feed appears
